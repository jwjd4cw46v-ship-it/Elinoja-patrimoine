# avis-experts

Répertoire pour le composant "avis-experts" côté client.

Objectif:
- Regrouper les composants React/TS liés aux avis d'experts
- Contenir les styles, hooks et tests associés

Structure proposée (à compléter):
- components/  -> composants réutilisables
- styles/      -> styles / CSS / SCSS
- hooks/       -> hooks spécifiques
- __tests__/    -> tests unitaires

Ce fichier existe uniquement pour s'assurer que le répertoire est bien versionné dans Git.
