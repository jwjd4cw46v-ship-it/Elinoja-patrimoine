=====================================================
   ÉTAPES DE MISE EN LIGNE (téléphone uniquement)
=====================================================

1. SUPABASE (supabase.com)
   - Créer un projet
   - SQL Editor → coller le contenu de :
     supabase_migrations_001_schema_complet.sql
   - Authentication → Users → créer votre compte admin
   - SQL Editor → exécuter :
     UPDATE profiles SET role = 'admin' WHERE email = 'votre@email.com';
   - Récupérer : Project URL + anon key + service_role key

2. GITHUB (github.com)
   - Créer un repo "elinoja-patrimoine"
   - Créer chaque fichier via "Add file → Create new file"
   - Taper le chemin DESTINATION (colonne droite ci-dessus)
     ex: app/admin/clients/page.tsx
   - Coller le contenu du fichier correspondant

3. VERCEL (vercel.com)
   - Connecter avec GitHub
   - Importer le repo
   - Ajouter les 4 variables d'environnement :
     NEXT_PUBLIC_SUPABASE_URL
     NEXT_PUBLIC_SUPABASE_ANON_KEY
     SUPABASE_SERVICE_ROLE_KEY
     NEXT_PUBLIC_APP_URL
   - Deploy !
